D&D 3.5 • ajuste pontual

Abrir na Ficha / Criação

Este ajuste faz com que, após o login do jogador, o site abra diretamente na aba Ficha (ou Criação, se o personagem não estiver concluído). Não muda o Firebase, os itens nem as magias.

  1. No seu repositório do GitHub, abra o arquivo index.html da versão atual e baixe-o em Download raw file (ícone de download).
  2. Escolha esse arquivo no campo abaixo.
  3. Clique em Baixar index.html corrigido e envie o arquivo obtido de volta para o GitHub, substituindo o antigo.
Selecione o arquivo para começar. Tudo funciona localmente; seu código não é enviado a nenhum servidor.

Importante: use o arquivo atualizado que está publicado no GitHub, não uma cópia antiga. O ajuste altera somente a escolha da aba após o login. Caso sua versão tenha uma estrutura diferente, o aplicativo avisará e não fará modificações.
